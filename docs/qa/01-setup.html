CMS manual QA

01 · Setup, install & configuration

Installing the CMS from a clean checkout, configuring the environment file, running migrations and seeds, first sign-in, module switches, languages, a moved admin path, the edit-lock relay, the CMS updater, security headers, robots.txt and the shipped user guides. You need a terminal on the test machine, an empty MariaDB/MySQL database you may drop, database client access, and two browsers (or one normal and one private window).

Prerequisites & environment file

Run these in the project folder of a fresh checkout. Commands are typed in a terminal; the file .env.local sits in the project root.

Check Node and npm versions

  1. Run node -v and npm -v.
  2. Open .nvmrc and the engines block of package.json.

Expected: .nvmrc says 20.18.0. Node is at least 20.9.0 and below 25; npm is at least 10 and below 12. If nvm is installed, nvm use switches to 20.18.0.

Ref: .nvmrc · package.json · docs/LOCAL_SETUP.md §1

Install dependencies with npm ci

  1. Run npm ci.
  2. Run npm audit --omit=dev.

Expected: npm ci finishes without an error and creates node_modules. npm audit --omit=dev reports 0 vulnerabilities. (A plain npm audit may report 4 moderate esbuild advisories from drizzle-kit; that is known and accepted. Do not run npm audit fix.)

Ref: package.json (//audit-esbuild note) · docs/LOCAL_SETUP.md §2

Create .env.local with the required values

Preconditions: An empty database created with CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci and a user granted on 'user'@'%' (see docs/LOCAL_SETUP.md §3).

  1. Run cp .env.example .env.local.
  2. Fill DB_HOST=127.0.0.1, DB_PORT, DB_USER, DB_PASSWORD, DB_NAME for the test database.
  3. Run openssl rand -base64 48 twice and paste the two outputs into ADMIN_SESSION_SECRET and CMS_TOKEN_ENCRYPTION_KEY.
  4. Leave NEXT_PUBLIC_SITE_URL=http://localhost:3002 as shipped (or set it to the exact origin of the test environment).

Expected: Each secret is 64 characters long (at least 32 is required). .env.example already ships NEXT_PUBLIC_SITE_URL=http://localhost:3002 and ADMIN_PATH=admin. No other value is needed to start the app.

Ref: .env.example · docs/LOCAL_SETUP.md §4 · docs/dev-guides/01-architecture.md §7.1

  • ADMIN_MFA_BYPASS_CODE is blank, with a comment warning it works in every environment.
